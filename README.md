RaceDay
RaceDay is a web-based system for managing running, walking and cycling events in South Africa.
The system allows organisers to create and manage events, categories, participants and results. Participants can view events, enter races and track their results.

User Roles
Organiser
Organisers can create, edit and delete events. They can also manage categories, view participants and add results.

Participant
Participants can create an account, view upcoming events, enter an event and check their results.
